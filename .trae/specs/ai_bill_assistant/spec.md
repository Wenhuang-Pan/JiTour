# 规格：账单 AI 助手（智谱 GLM-4-Flash 对接）

## 问题

当前统计页仅提供图表与数字汇总，缺乏智能解读。用户面对一堆数字无法快速理解消费结构是否合理、是否有异常支出、如何优化储蓄。需要引入 AI 分析能力，将脱敏的账单汇总数据发送给大模型，返回自然语言分析建议。

## 用户与目标

- **用户**：希望获得智能消费分析的记账用户
- **目标**：在统计页提供「AI 分析」入口，用户可获取消费结构解读、异常支出提醒、储蓄建议等自然语言分析
- **非目标**：
  - 不做 AI 自动记账（分类推断已有 CategoryInferenceService）
  - 不做 AI 对话式聊天（仅提供预设分析模板 + 结果展示）
  - 不发送完整账单明细到第三方（仅发送分类汇总）
  - 不硬编码 API 密钥（用户自行配置）

## 约束与依赖

- LLM：智谱 GLM-4-Flash（永久免费，国内直连，API 兼容 OpenAI 格式）
- 网络：依赖 `http` 包（项目已有）
- 存储：API Key 存 Hive（不硬编码），分析结果可选缓存
- 隐私：仅发送分类维度汇总数据，不发送账户名、完整商户名、用户身份信息
- 项目规则：禁 `dynamic`、泛型显式；public 方法需 dartdoc；异常需日志+用户提示

## 功能需求

### FR-1 API Key 配置
- 设置页新增「AI 助手」入口，用户可输入/保存/清除智谱 API Key
- API Key 存储在 Hive 独立 box，不硬编码
- 未配置 API Key 时，AI 分析入口提示用户先配置

### FR-2 AI 分析服务（AiAnalysisService）
- 封装智谱 GLM-4-Flash API 调用（OpenAI 兼容格式：`POST https://open.bigmodel.cn/api/paas/v4/chat/completions`）
- 输入：脱敏的账单汇总数据（期间、收支总额、分类占比、最大单笔、日均）
- 输出：AI 分析文本
- 异常处理：网络失败、API Key 无效、额度耗尽等需捕获并友好提示
- 超时控制：30 秒超时

### FR-3 数据脱敏与组装
- 从 TransactionService 拉取指定期间的交易
- 聚合为分类维度汇总（不包含商户名、账户名）
- 构造 Prompt 发送给 LLM

### FR-4 AI 分析 UI
- 统计页右上角新增「✨ AI」按钮
- 点击进入 AI 分析页，提供 3 个预设分析模板：
  1. 「消费结构分析」
  2. 「异常支出提醒」
  3. 「储蓄优化建议」
- 点击模板后展示加载状态，返回后展示分析文本
- 支持重新分析

## 非功能需求

- 性能：单次请求 < 10 秒（GLM-4-Flash 响应较快）
- 成本：GLM-4-Flash 永久免费，无调用限制
- 隐私：首次使用弹窗告知数据用途；设置页可关闭 AI 功能
- 兼容：Android（iOS 不在本项目范围）

## 验收标准

### AC-1（rule）API Key 配置与存储
用户在设置页输入 API Key 并保存后，重启应用 Key 仍存在；清除后 Key 被删除。Key 不硬编码在代码中。

### AC-2（rule）AI 分析服务调用成功
配置有效 API Key 后，调用分析服务能返回非空文本结果。无效 Key 或网络失败时抛出可捕获的异常并给出用户提示。

### AC-3（rule）数据脱敏
发送给 LLM 的数据中不包含账户名、完整商户名、用户身份信息，仅包含分类汇总与金额统计。

### AC-4（rule）未配置 Key 时阻止分析
未配置 API Key 时点击 AI 分析，引导用户去设置页配置，不发起网络请求。

### AC-5（rule）全量编译通过
`flutter analyze` 0 issue；`flutter test` 全通过（含新增的 AiAnalysisService 单测，mock http 响应）。

### AC-6（rubric）UI 体验
维度：AI 分析流程流畅度。0 分：入口难找/加载无反馈/错误无提示；1 分：流程可用但交互粗糙；2 分：入口明显、加载有动画、错误有友好提示、结果易读。阈值 ≥ 2。
