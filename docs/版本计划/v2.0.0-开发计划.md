## 🎯 v2.0.0 计划新增功能

### 1. 多账户管理（高优先级）
- 支持多个账户（现金、银行卡、支付宝、微信等）
- 账户余额追踪
- 账户间转账功能
- 账户切换界面

### 2. 账单周期管理（高优先级）
- 支持自定义账单周期（月度/双周/周）
- 账单周期切换
- 周期结算提醒

### 3. 标签系统（中优先级）
- 为交易添加自定义标签
- 标签筛选和搜索
- 标签统计分析

### 4. 目标与储蓄计划（中优先级）
- 创建储蓄目标
- 进度追踪
- 目标完成提醒

### 5. 数据可视化增强（中优先级）
- 趋势图表（月度/年度对比）
- 收支流水时间线
- 预算使用进度条

### 6. 通知与提醒（中优先级）
- 账单到期提醒
- 预算超支提醒
- 定期备份提醒

### 7. 导入银行账单（低优先级）
- 支持 CSV/Excel 导入
- 智能分类匹配
- 导入历史记录

### 8. UI/UX 优化（持续进行）
- 深色模式
- 主题颜色自定义
- 手势操作支持
